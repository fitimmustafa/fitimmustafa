I build web applications end to end — database, API and interface — and bring
AI into products where it does real work. I started in frontend, moved into
the backend, and today most of my time goes into full-stack product work and
AI integrations.

### What I work on

- 🧱 **Full-stack web applications** — React and Next.js on the front, Node.js and NestJS behind, PostgreSQL underneath
- 🏢 **SaaS and multi-tenant systems** — role-based access, data that stays separated per customer, admin dashboards and CRMs
- 🤖 **AI features in production** — natural-language search, document and CV extraction, generated content, matching and ranking
- 🌍 **Multilingual products** — Albanian, English and German, from the interface to transactional email
- 🛍️ **Websites and stores** — fast, responsive company sites, Shopify and WordPress

### How I build

- **AI with a safety net.** Every model call has a deterministic path behind it, so a slow or wrong answer degrades a feature instead of breaking it.
- **Grounded output.** Generated text comes only from the data it was given, and a person reviews anything that leaves the system.
- **No lock-in.** Several LLM providers behind one layer, so switching is configuration, not a rewrite.
- **Tested releases.** Vitest and Playwright running in CI, end to end against a real database.
